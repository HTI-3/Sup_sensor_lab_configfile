SensorLab → SENSORS.CFG

Turn SensorLab codes into sections for the camera's \fpSup\SENSORS.CFG. Everything runs in this page, offline.

1

Paste links

The camera's QR code or the SensorLab page's address, one per line. A 12-bit and a 14-bit code of the same crop and size become one format.

2

Name each link

The id is what the camera remembers the format by (1–8 of A–Z 0–9 _, at most 5 with a 14-bit link). The menu name is the Resolution row's text. Leave a box empty for the default shown in it; a link left blank joins the format its crop and size already have an id for. Different ids keep links apart.
